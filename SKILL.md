# Where the skill lives

The real skill is at `.claude/skills/youtube-video-pipeline/SKILL.md`.

Claude Code only auto-discovers skills inside `.claude/skills/<name>/`, so that is
where it has to sit. This file is here so anyone who goes looking for `SKILL.md`
at the root finds the pointer instead of nothing.

To run it: open this folder in Claude Code and type `/youtube-video-pipeline`,
or just describe what you want ("make me a new video") and it will load itself.
